# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-06-19

### Added
- Initial release: Full self-hosted video platform
- User auth (register, login, logout, forgot password with token)
- Video upload (single + bulk with real-time progress)
- Automatic FFmpeg thumbnail & metadata extraction
- Custom responsive HTML5 player (PiP, speed, fullscreen, seek)
- Multiple share links + iframe embed code generator
- User dashboard with folders, search, video management
- Admin panel with user/video management, storage stats, activity logs
- View analytics (total, unique, duration) per video and global
- RESTful API with API key auth for uploads
- Docker Compose production setup with Nginx
- Security hardening (JWT httpOnly, rate limits, validations)
- Professional documentation

## [Unreleased]
- Planned: HLS transcoding worker, subtitle support, comments, advanced search
